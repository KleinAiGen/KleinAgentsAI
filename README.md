## How to Use Agent Search

1. Click on the "Agent Library" button in the sidebar.
2. Use the search bar at the top of the modal to search for agents by name, skill, or description.
3. You can also filter agents by category using the sidebar in the library modal.

### What if I can't find an agent?

If your search query returns no results, a **"Generate Custom Agent"** button will appear. 

1. Click the "Generate Custom Agent" button.
2. The AI will generate a new agent profile based on your search query.
3. Once generated, you can save it to your library for future use.
