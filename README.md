# AgentKlein AI

AgentKlein AI is an advanced AI-powered chat interface designed for productivity, development, and data analysis. It leverages powerful models like Gemini Pro and Qwen 3.5 to provide a versatile and intelligent assistant experience.

## Features

- **Agent Library:** Access a wide range of specialized AI agents for various tasks.
- **Custom Agent Generation:** Can't find the perfect agent? Generate a custom one tailored to your specific needs.
- **Multi-Model Support:** Switch between different AI models to suit your requirements.
- **Data Management:** Export and import chat history easily.
- **Rich Interaction:** Support for image uploads, code highlighting, and markdown rendering.

## Requirements

- **Node.js:** Ensure you have Node.js installed (v18+ recommended).
- **API Keys:** You will need a valid `GEMINI_API_KEY` to use the Gemini models.

How to Use Agent Search

    Click on the "Agent Library" button in the sidebar.

    Use the search bar at the top of the modal to search for agents by name, skill, or description.

    You can also filter agents by category using the sidebar in the library modal.

What if I can't find an agent?

If your search query returns no results, a "Generate Custom Agent" button will appear.

    Click the "Generate Custom Agent" button.

    The AI will generate a new agent profile based on your search query.

    Once generated, you can save it to your library for future use.
